# 业务规则

## 用户和数据权限

- 注册只创建 `STUDENT`；管理员创建 `TEACHER`。密码只保存 BCrypt 哈希。
- 教师只能管理自己负责班级对应的课次、考勤、作业、考试和自己的题库；服务端用 JWT 主体 ID 校验，忽略客户端伪造教师 ID 的授权意图。
- 学生只读取本人订单、成员班级、考勤、作业、考试成绩、提交和通知。

## 课程、班级和名额

- 课程先创建为草稿，上架后才允许开放其教学班报名；下架课程不再开放报名。
- 一个班级关联一门课程和一名主讲教师。课程和班级分离，学生通过 `class_student` 关联到班级。
- `reserved_count` 和 `enrolled_count` 由订单事务维护，API 不接收这两个字段。任何容量变更都必须保持 `capacity >= reserved_count + enrolled_count`。
- 班级可以取消的前提是尚未开始教学且没有有效报名。课程、班级和有历史教学记录的课次没有物理删除接口。

## 订单与支付

- 只有 `ENROLLING` 班级接受订单。创建订单先原子预占名额，价格保存为订单快照。
- 每个学生同一班级最多一个有效待支付订单；重复请求复用仍有效的订单。正式入班仅在模拟支付成功时发生。
- 同一学生同一课程最多加入一个报名中或教学中的班级；同课程不同班级也不能重复报名。已有有效待支付订单时需先处理原订单，不能跨班重复占位。下单和支付均按学生加锁检查，旧待支付订单也不能绕过限制；班级已结课后允许再次报名。
- `PENDING` 可转为 `PAID`、`CANCELLED` 或 `EXPIRED`；终态重复处理不重复调整容量计数。
- 超时根据数据库 UTC 时间判定。RabbitMQ TTL/DLX 发送过期事件，扫描任务补偿消息未到达的订单。

## 排课

- 教室可用、教师有效，教室容量不小于班级容量，课次时间合法并落在教学日期范围内。
- 重叠条件为 `existing.start_time < new.end_time AND existing.end_time > new.start_time`，所以区间为 `[start,end)`，相邻课次可连续安排。
- 冲突覆盖教师、教室、班级三种资源。事务固定按教师、教室、班级加锁后重新查询，避免并发排课产生重复占用。

## 考勤、作业与通知

- 每个课次的学生考勤按课次和学生唯一；教师只能记录自己课次中正式入班学生。
- 作业草稿可编辑，发布后学生可在截止时间前提交或更新；已批改提交不可覆盖。教师只能批改自己班级的作业。
- 作业发布事件驱动站内通知，重复投递不会重复创建通知。用户只能查看或标记自己的通知。
- 教师只能在课次结束后确认课次完成；班级正式成员都必须有一条考勤记录。课次完成后考勤不可再编辑。
- 班级状态改为 `FINISHED` 需要结束日期已过、至少有一个计划课次、所有计划课次均已完成且考勤完整；同时关闭已发布作业和考试、批改完已提交作业及简答题。结课和教师发布新教学任务通过班级行锁串行化。

## 看板与教学分析

- 学生看板通过登录主体 ID 过滤班级、作业、考试、成绩和未读通知。
- 管理员看板的金额仅为模拟支付流水聚合值，不是真实收款或营收口径。
- 班级平均分、最高/最低分和及格率按已完成阅卷的考试尝试聚合；分数为原始分，及格线为该考试题目快照总分的 60%，50 分试卷的及格线为 30 分。未完成主观题批改的答卷不计入最终成绩统计。
- 后端业务时间使用 UTC；前端转换为浏览器所在时区并显示时区名称，开课日期等纯日期字段不做时区转换。
- 出勤率以已完成课次中 `PRESENT` 和 `LATE` 记录数除以应登记考勤人数统计；作业完成率以提交数除以已发布/关闭作业应交人数统计。

## 考试

- 教师只可为自己负责的班级创建考试，使用自己的题库组卷。发布后快照题面、选项、答案、分值和顺序。
- 学生须属于考试班级且在考试时间范围内；每场考试每个学生一次尝试。学生接口不返回正确答案。
- 单选、多选、判断自动评分；多选答案按集合完全匹配；简答题由教师评分。所有主观题评分完成后才对学生开放最终成绩。
- 超过考试时长后由服务端提交作答并自动阅客观题；学生不能延长客户端计时或篡改分值。
- 学生作答在 `IN_PROGRESS` 状态下可暂存；保存操作校验本人班级、唯一尝试和截止时间。刷新或重新进入考试时恢复草稿；最终提交与超时收卷均使用已保存答案计算客观题成绩。

## 操作审计与缓存

- 已认证用户对 `/api` 的 POST、PUT、PATCH、DELETE 请求记录操作元数据；审计不存储请求体、密码、JWT 或答案内容。
- 课程详情 Redis 失效在事务提交后立即执行，并有 MySQL 失效任务补偿；缓存故障不改变 MySQL 中的课程数据。
