## 修复

| 问题 | 修复 |
| --- | --- |
| 修改个人姓名使用整个用户实体，可能覆盖管理员并发修改的账号状态 | 只更新姓名字段 |
| 班级修改先读快照再等锁，后续课次检查可能使用旧快照 | 修改事务使用 READ_COMMITTED；状态变更核对课程与教师是否改变 |
| 已有作业的草稿班级更换教师/课程后，作业归属与班级不一致 | 有作业或考试时禁止更换课程/教师 |
| 下单读取课程后，班级可能在预占名额前被管理员调整 | 预占成功持有班级锁后重新核对课程并读取价格；变化则回滚 |
| 已完成课次没有参与时间冲突检查 | 教师、教室、班级冲突查询同时涵盖待上和已完成课次，保留 FOR UPDATE；查询迁移至 XML |
| Redis 的 CacheErrorHandler 仅声明为 Bean，未通过 Spring 缓存配置接口接入 | 实现 CachingConfigurer.errorHandler，缓存读取异常可回源数据库 |
| 题目选项/参考答案仅校验 JSON，非法类型及不存在的答案选项可入库 | 按题型校验类型、选项数量、唯一标识及答案归属；题目修改与停用共用行锁 |
| 答案保存/提交/超时收卷等待答卷锁后可能读到旧答案 | 考试写事务使用 READ_COMMITTED，保持答卷行锁串行化 |
| 清空答题时 SQL NULL 被 MyBatis 默认非空更新策略忽略 | 显式存储 JSON null，能够覆盖原答案 |
| 已过期考试草稿仍能发布；过期答卷重新进入仍短暂显示答题中 | 禁止发布已截止考试；重新进入时立即完成超时收卷 |
| 教师关闭考试时仍有学生答题，状态冲突 | 有进行中答卷时拒绝关闭，等待提交或超时收卷 |
| 提前交卷可以从成绩接口读到参考答案 | 考试关闭或整体结束前隐藏参考答案 |
| 页面快速切换/考勤和成绩下拉切换，旧响应可能覆盖当前数据 | 页面请求序号及选中 ID 检查；切换课次先清空名单 |
| 考试列表受其他页面残留班级选择影响，但没有可见过滤条件 | 显示该教师全部考试 |
| 管理页面会把接口提供的姓名覆盖成第一页查询的 ID 回退值；教师班级表仍显示 ID | 优先使用后端姓名，教师班级表显示课程名及教师名 |
| 交卷依赖额外草稿保存成功，草稿失败可能挡住最终提交 | 等待已发出的保存请求后直接提交完整答案 |
| Dashboard 重复注册未授权监听且不释放答题定时器；损坏本地登录 JSON 可造成白屏 | 由路由统一处理未授权，离开页面清理计时器；安全读取登录缓存 |
| 支付接口返回已过期订单时，页面仍显示支付成功 | 根据返回订单状态提示；超时提示重新报名 |
| 错误请求方法、并发锁冲突落入通用 500 | 分别返回 405 和可重试的 409 |
